The first command is the ten-node bottleneck test. The second increases capacity on SA, AD, DG and GT from one to two packets per tick. Both use the same nine loads, ten seeds and 5,000 ticks. Each run asserts packet conservation. Every output directory contains raw `results.csv`, mean `summary.csv`, and graphs.

## Network

The directed nodes are S, A, B, C, D, E, F, G, H and T. Fifteen links create seven possible S-to-T paths. `TEN_NODE_TOPOLOGY.png` labels every link ID. The report lists delay, capacity and FIFO size for all links, plus the exact seven routes.

The baseline uses fixed delay weights. Queue-aware Dijkstra uses `w = delay * (1 + alpha * q / buffer_size)`, with alpha 2.5 and a five-tick update interval. `q` is the peak number of packets waiting in the FIFO during the preceding update interval. The route is cached between updates. In-flight packets do not count as waiting queue occupancy.
